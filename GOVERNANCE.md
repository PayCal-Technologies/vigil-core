# Governance

Vigil is maintained by PayCal Technologies.

The public repository accepts issues and pull requests for the open-source CLI,
documentation, examples, packaging, and public extension manifests. Maintainers
decide release timing, compatibility policy, and project scope.

Project principles:

- local-first operation;
- explicit mutation boundaries;
- deterministic machine-readable output;
- clear setup paths for new users;
- no private deployment assumptions in the public repository.

Compatibility and safety changes use the public
[RFC process](docs/rfcs/README.md). Maintainer decisions record rationale,
migration, rollback, and any unresolved dissent.
